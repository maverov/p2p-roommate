🔴 Critical Issues (Must Fix)

Critical Missing Database Check Constraints

Files: db/schema.ts (lines 343, 154, 190-191)

Issue: Rating, response_rate, and monetary fields allow invalid values via SQL.

  • Rating: Allows any integer (should be 1-5)
  • Response rate: No bounds (should be 0-100)
  • Rent/deposit: Can be negative

Impact: Data integrity violation

Action: Add migration 0004 with CHECK constraints immediately

Critical Authorization Gap in DELETE Operations

Files: DELETE endpoints (favorites, saved-searches, viewing-requests)

Issue: Silent success on non-existent records. Deleting twice returns 204 both times.

Impact: Hides bugs and race conditions

Action: Return 404 if nothing was deleted OR document idempotent behavior

High Missing Composite Database Indexes

File: db/schema.ts

Missing:

  • reviews(targetType, targetUserId)
  • reviews(targetType, listingId)
  • listings(status, publishedAt)
  • viewingRequests(listingId, status)

Impact: Query performance degrades with data growth

Action: Add in migration 0004

🟡 High Priority Issues (Should Fix)

High Account Table Missing Uniqueness Constraint

File: db/schema.ts:51-74

No unique constraint on (accountId, providerId) combination. Duplicate OAuth entries possible.

Fix: Add UNIQUE constraint in migration

High Inconsistent API Response Format

Files: Multiple API routes in app/api/*

Different endpoints return different response shapes (items, listings/profiles, etc.)

Impact: Client code must handle multiple formats

Fix: Standardize to consistent response envelope

High Denormalized Metrics Not Synchronized

File: db/schema.ts:154-155

responseRate and successfulRentals are manually maintained with no automatic sync.

Risk: Stale data, incorrect sorting/filtering

Fix: Use triggers, compute on-the-fly, or scheduled jobs
