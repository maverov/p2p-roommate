[ ] 2. Privacy policy and terms
       Both pages are drafts with placeholder text. GDPR requires a real
       privacy policy before the site collects personal data.
       Start this first: the lawyer is the longest step.

[ ] 3. Email (Resend)
       - Verify rentbee.bg for sending (add the DNS records Resend gives you)
       - Set RESEND_API_KEY and EMAIL_FROM=RentBee <noreply@rentbee.bg>
       Blocker: sign-up requires email verification, so without email
       nobody can create an account.

[ ] 4. Photo uploads (Vercel Blob)
       - Create the Blob storage
       - Set BLOB_READ_WRITE_TOKEN
       Without it, owners cannot add photos.

[ ] 5. Production database
       - Choose a managed Postgres that includes connection pooling and
         automatic backups (one provider can cover both)
       - Use its pooled connection URL for DATABASE_URL, and set
         DATABASE_POOL_MAX=1
       - Apply migrations:          pnpm db:migrate
       - Provision the sole admin: pnpm admin:setup
         Only maverov@gmail.com may be admin (display name: admin).

[ ] 6. Hosting settings
       - BETTER_AUTH_SECRET: a new random value, 32+ characters
       - BETTER_AUTH_URL and NEXT_PUBLIC_APP_URL: https://rentbee.bg
       - Add rentbee.bg and www.rentbee.bg to Vercel; redirect www to rentbee.bg
       - Add the exact DNS records Vercel supplies in the active DNS zone

[ ] 7. Map tiles
       Set NEXT_PUBLIC_MAP_TILE_URL (and NEXT_PUBLIC_MAP_ATTRIBUTION) for a
       tile provider. The default uses OpenStreetMap's own servers, which
       allow development and light use only.

[ ] 8. Favicon and share image
       Text branding is complete; the RentBee image assets are still missing.
       The site points to these files, but they don't exist yet:
         public/favicon.ico
         public/favicon-16x16.png
         public/apple-touch-icon.png
         public/og-image.png   (1200 x 630, shown when a link is shared)
       Also add a square logo (at least 112 x 112) and the real social

       the logo. Both are left out until they exist.
       Every page asks for the missing favicon, and shared links show no
       image. Once the files are there, wiring them in takes minutes.

[ ] 9. Error monitoring
       So you find out when something breaks in production.

[ ] 10. Contact addresses
       The Contact us and Press office pages show placeholder addresses
       (support@, safety@, press@ and partners@rentbee.bg). Create the real
       mailboxes, or change them in lib/company.ts, which updates every page.
       Bulgarian e-commerce law (ЗЕТ, чл. 4) also requires the operator's
       legal name, address and company number (ЕИК) on the site, usually on
       Contact us or in the footer. None of that is shown yet.
